# Archilab RPA2024 Studio — v1.7.0

Première diffusion publique du studio de calcul **RPA 2024 / BAEL 91** pour
l'Algérie. Deux applications Windows sont fournies dans cette release : aucune
installation de Java, de Python ou de Git n'est nécessaire.

## Téléchargements

| Fichier | Description | Prérequis |
| --- | --- | --- |
| `ArchilabRPA2024-Studio-1.7.0-Windows.exe` | Application Kotlin / Compose Desktop, interface complète et modules experts | Windows 10/11 64 bits |
| `ArchilabRPA2024-Python-1.7.0-Windows.exe` | Application Python autonome (CustomTkinter) pour postes sans Java | Windows 10/11 64 bits |
| `SHA256SUMS.txt` | Empreintes SHA-256 des deux exécutables | — |

Les exécutables ne sont pas signés numériquement : au premier lancement,
Windows SmartScreen peut afficher « Informations supplémentaires » →
« Exécuter quand même ». Vérifiez d'abord l'empreinte SHA-256.

## Contenu de la version

- Ingestion ETABS (`.e2k`, `.xlsx`, `.mdb`, `.txt`) et SAFE (tableaux tabulés,
  ressorts de sol, déplacements, efforts).
- Moteur sismique RPA 2024 (DTR BC 2.48) : participation modale, calibration
  MSE/MDS, effort tranchant à la base, dérives νA, P-Delta (θ), coefficients de
  comportement.
- Vérifications BAEL 91 révisé 99 / CBA 93 : poteaux, poutres, voiles,
  fondations filantes, sections en T, poinçonnement.
- Audits CTC : régularité b1–b3, joints sismiques, poteau fort / poutre faible,
  contrôle de vérifiabilité des données.
- Ferraillage commercial constructible, auto-redimensionnement par pas de 5 cm.
- Note de calcul CTC de 13 chapitres en Word (équations OMML natives) et PDF,
  avec 20 repères de captures contrôlés.
- Plans DXF de coffrage, ferraillage et nomenclature, plus DQE acier XLSX.
- Persistance SQLite multi-projets.
- Version Python autonome : imports ETABS/SAFE, note de calcul de 13 chapitres
  avec 21 emplacements de captures, plans DXF/SVG et nomenclature.

## Validation

- Kotlin : **106/106 tests** JUnit 5, 0 échec.
- Python : **19/19 tests** (`unittest`).
- Plans DXF contrôlés avec `ezdxf` : 0 erreur sur les maquettes de démonstration.

## Limites connues

- Les essais sont réalisés sur des exports de référence et des maquettes de
  démonstration ; aucune validation en session live ETABS/SAFE/AutoCAD n'est
  revendiquée dans cette version.
- La redistribution des efforts après changement de section exige une
  réexécution de l'analyse dans ETABS/SAFE ; le rapport le signale.
- Les captures de projet ne sont jamais fabriquées : elles sont associées
  manuellement dans l'application ou extraites d'un DOCX de référence.
- Les résultats restent soumis à la validation d'un ingénieur qualifié et de
  l'autorité de contrôle compétente.
